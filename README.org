* Overview

*eglot-lsp-settings* provides automatic language server installation for [[https://github.com/joaotavora/eglot][Eglot]], the built-in LSP client in Emacs. Powered by [[https://github.com/mattn/vim-lsp-settings][vim-lsp-settings]], it offers seamless setup for a wide variety of programming languages without manual configuration.

[[https://github.com/conao3/eglot-lsp-settings.el][https://raw.githubusercontent.com/conao3/files/master/blob/eglot-lsp-settings.el/eglot-lsp-settings.gif]]

** Features

- Automatic installation of language servers via interactive selection
- Support for 100+ language servers through vim-lsp-settings
- Minimal configuration required
- Cross-platform support (Linux, macOS, Windows)

* Requirements

- Emacs 26.1 or later
- Git (for cloning vim-lsp-settings)
- Build tools required by individual language servers

* Installation

** Using package.el

#+begin_src emacs-lisp
(package-install 'eglot-lsp-settings)
#+end_src

** Using leaf.el

#+begin_src emacs-lisp
(leaf eglot-lsp-settings :ensure t)
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package eglot-lsp-settings
  :ensure t)
#+end_src

* Usage

To install a language server, run:

#+begin_src
M-x eglot-lsp-settings-install-server
#+end_src

Select the desired server from the completion list. The installation progress is displayed in the =*eglot-lsp-settings*= buffer.

After installation, start Eglot in your project with =M-x eglot=.

* Configuration

** Custom Installation Directory

#+begin_src emacs-lisp
(setq eglot-lsp-settings-dir (expand-file-name "~/.local/share/eglot-lsp-settings"))
#+end_src
